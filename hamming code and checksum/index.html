⚡ Extended Hamming 2-Bit Correction Resolver (Syndrome + RFC 1071 Checksum Tie-Breaker):
SEC-DED flags a double-bit error because S ≠ 0 and P_check is even. In binary Hamming codes, any candidate pair (i, j) satisfies i ⊕ j = S. The Internet Checksum tests each candidate to isolate the true flipped bits:
Internet Checksum Algorithm (RFC 1071): Data is parsed into 16-bit big-endian words. The words are summed using 1's complement arithmetic (any carry past 16 bits wraps around and adds to the least-significant bit). The total sum is then bitwise inverted (NOT).
Parity Check Matrix (H): In Hamming codes, each column j of the parity check matrix is the binary representation of index j. Multiplying H by the received column vector r produces syndrome S = H · r.
